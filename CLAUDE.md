# Projet Godot

Ce que Claude doit savoir de **ce jeu** : son genre, sa vision (`docs/vision.md`), son organisation, ses conventions et les pièges rencontrés. Ce fichier appartient au jeu : `mise run template-update` n'y touche pas. Les règles communes à tous les jeux du template (commandes, vérification, kit, conventions, pièges) sont dans `.claude/rules/socle.md`, chargé à chaque session et mis à jour avec le socle.

Dans le template lui-même, ce fichier ne dit rien de plus : un jeu le remplit dès `/new-game`.
